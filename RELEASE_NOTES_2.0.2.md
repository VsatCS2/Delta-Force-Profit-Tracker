# Delta Force Profit Tracker v2.0.2

## What's new

**Starts with Windows (new installs).** The installer now asks whether DF Tracker should start when Windows does, and the box is ticked by default, so most people won't have to remember to turn it on. It starts minimized so it doesn't pop a window up at login. You can untick it in the installer, or change it any time in **Settings → Startup**. If you already have DF Tracker installed, an update never changes your current setting.

**One copy at a time.** If DF Tracker is already running (in the tray, minimized or open) and you launch it again, the running window comes to the front instead of a second copy opening.

**A "Get DF Tracker" button on your Discord status.** When Discord Rich Presence is on, people who see you using DF Tracker now get a button that opens the website, so they can get the app too. You can turn it off any time in **Settings → Discord Rich Presence**. Discord shows the button to other people, not to you on your own profile, and its phone app doesn't show buttons.

## Updating

- **On 2.0.1, 2.0.0 or 1.5.0:** open **Settings → Check for Updates** and let the app install it.
- **New to DF Tracker:** download `DeltaForceTracker-Setup-2.0.2.exe`.
- `DeltaForceTracker.zip` is the same program as a plain folder (it's also what the in-app updater downloads). Extract the whole folder, not just the `.exe`.
