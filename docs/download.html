Download DF Tracker for Windows

Free. Version 2.1.0. Windows 10 and 11.

Download from GitHubInstaller and a ZIP are on the release page.
  1. DownloadGrab the latest installer from the releases page on GitHub.
  2. Run itOpen the installer. It can start DF Tracker with Windows, minimized, if you tick the box.
  3. Sign inUse your Delta Force account and your matches load in. Sign in with Discord too if you want player lookup.

Good to know

  • Windows only. Windows 10 or 11.
  • Updates itself. After the first install, new versions download in the background and install when you choose Restart and Update.
  • Overlays need windowed or borderless mode, not exclusive fullscreen.

If Windows shows a warning

DF Tracker isn't code-signed yet, so Windows SmartScreen may show "Windows protected your PC" for a new download. Choose More info, then Run anyway.

Every release lists a SHA-256 checksum, so you can confirm your download matches the file we published.

Source and releases

DF Tracker's code and every past version are on GitHub. See what changed in each version on the changelog.
